# Heatmaps (React + Capacitor)

## First-time setup
    npm install
    npm install @capacitor/core @capacitor/android
    npm install -D @capacitor/cli
    npm run build
    npx cap add android

## Run
- In the browser: `npm run dev`
- On Android: `npm run android` (builds, syncs, opens Android Studio; press Run there)

Requires Node 18+ and Android Studio.
